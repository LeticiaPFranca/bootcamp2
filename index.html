Endereço inteligente
com ViaCEP + Google Maps

Nunca mais perca tempo digitando endereços. Informe o CEP e o MedControl preenche tudo automaticamente — logradouro, bairro e cidade.

  • 1
    Digite o CEP do idoso Campo dedicado na tela de perfil, aceita CEP com ou sem traço.
  • 2
    Clique em "Buscar CEP" A API pública do ViaCEP é consultada em segundo plano — sem travar a tela.
  • 3
    Endereço preenchido automaticamente Logradouro, bairro e cidade/UF aparecem nos campos em instantes.
  • 4
    Abra o Google Maps com um clique O botão "Traçar Rota" abre o navegador diretamente na localização do idoso.

Instalação

Como instalar e executar

O MedControl roda em qualquer computador com Python 3.10+. Siga os passos abaixo:

🐍 Python 3.10+ 🪟 Windows 10/11 🍎 macOS 12+ 🐧 Linux
Passo 1

Baixe o projeto

Clique em "Baixar Aplicativo" ou clone o repositório:

git clone https://github.com/SEU_USUARIO/medcontrol.git
Passo 2

Instale as dependências

Dentro da pasta do projeto, execute:

pip install -r requirements.txt
Passo 3

Execute a migração

Cria o banco de dados local:

python migrate.py
Passo 4

Inicie o aplicativo

Execute o programa principal:

python main.py
